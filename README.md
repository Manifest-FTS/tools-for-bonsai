# Tools for Bonsai

Public downloads for independent tools built by [Manifest FTS](https://manifestfts.com) to complement Bonsai workflows.

## Visual Feedback for Bonsai

Turn contextual website feedback into tasks in the correct Bonsai project.

[Download the latest Chrome extension](https://github.com/Manifest-FTS/tools-for-bonsai/releases/latest/download/visual-feedback-extension.zip)

### Install for testing

1. Download and extract the zip.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the extracted folder that directly contains `manifest.json` (not its parent Downloads folder).

Visual Feedback for Bonsai is an independent product and is not affiliated with or endorsed by Bonsai.
